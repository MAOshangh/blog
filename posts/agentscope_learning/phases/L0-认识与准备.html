AgentScope 是什么：先建立直觉

可以把多智能体框架想象成一个『乐高工厂』：Agent 是乐高小人，每个小人各司其职（一个负责策划、一个负责写作）；Msg 是小人之间传递的纸条；Pipeline 是把小人按顺序排成流水线的传送带。AgentScope 就是这套乐高的官方图纸和零件库——你不用自己实现『怎么让两个 AI 互相传话』，框架已经做好了。

为什么要用多智能体框架而不是直接调一个大模型 API？因为真实任务往往需要分工与协作：一个 Agent 负责拆解任务，另一个负责执行，第三个负责质检。每个 Agent 用不同的提示词和工具，各管一段，比让一个模型从头干到尾更可控、更容易调试。

AgentScope 的核心卖点就三件事：一是『高鲁棒』——内置超时控制、错误处理，多智能体系统不容易崩；二是『易用』——用 Python 函数式的写法就能创建和编排 Agent；三是『可视化』——有 AgentScope Studio 等工具能观察消息流和调用链，调试多智能体系统不再靠猜。

学完本节，你只需要记住一个定位：AgentScope 是帮你『用代码组装多个 AI 助手并让它们协作』的 Python 框架。

要点
  • AgentScope 是阿里巴巴开源的多智能体开发平台，定位是『组装多个 AI 助手并让它们协作』
  • 核心三卖点：高鲁棒（超时/错误处理）、易用（函数式写法）、可视化（Studio 调试）

安装与环境验证（动手第一步）

AgentScope 要求 Python 3.11 及以上版本。先确认你的 Python 版本，再安装框架。官方推荐用 uv 安装，也可以用 pip。

安装完成后做一次『冒烟测试』：import 框架并打印版本。如果 import 成功，说明安装没问题，可以进入下一阶段。这是每个新框架学习者的第一个成功体验，务必亲手敲一遍。

两个最常踩的坑：一是 Python 版本太低（3.10 及以下直接报语法错误或依赖不兼容）；二是同时装了多个 Python，导致 uv/pip 装的包和运行代码的 Python 不是同一个（用 python --version 与 pip show agentscope 交叉验证）。

uv pip install agentscope

准备模型 API Key（跑通一切的前提）

AgentScope 本身不内置大模型，它负责编排，真正『思考』的是你接入的模型服务。本教程默认使用阿里云百炼（DashScope）的 qwen 系列，因为它国内可直接访问、示例代码遍布官方文档。

你需要做三件事：注册 DashScope 账号、创建 API Key、把 Key 放进环境变量。官方示例统一用 os.environ['DASHSCOPE_API_KEY'] 读取，所以把你的 Key 设成同名环境变量，之后所有示例代码都能直接跑。

为什么不把 Key 直接写在代码里？一是安全：代码可能被分享、上传，Key 泄露等于别人花你的钱调用模型；二是习惯：真实工程里密钥永远走环境变量或密钥管理服务。养成『代码不写密钥』的习惯，从第一天开始。

操作步骤
  1. 注册阿里云百炼：https://bailian.console.aliyun.com/ ，实名认证后进入控制台
  2. 在控制台『API-KEY』页面创建密钥，复制保存
  3. 设置环境变量：Windows 用 setx DASHSCOPE_API_KEY "你的密钥"（新开终端生效）；macOS/Linux 用 export DASHSCOPE_API_KEY=你的密钥 写入 ~/.zshrc 或 ~/.bashrc
  4. 验证：终端运行 python -c "import os; print(bool(os.environ['DASHSCOPE_API_KEY']))"，输出 True 即成功
常见坑
  • 环境变量设了但读不到：setx 设置后必须重开终端；macOS 要 source 配置文件
  • Key 里带空格或引号：setx 的引号用法易错，设置后立刻用上面第 4 步验证
  • 账户无余额/未开通模型：百炼控制台检查是否开通 qwen 系列模型
要点
  • AgentScope 编排智能体，模型由你接入；本教程默认 DashScope qwen
  • API Key 放环境变量 DASHSCOPE_API_KEY，代码里用 os.environ 读取，禁止写死
  • Key 配好并验证通过，后续所有示例才能跑通

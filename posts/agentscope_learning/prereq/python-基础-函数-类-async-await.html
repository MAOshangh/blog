函数与返回值

函数是把一段可以重复使用的代码打包起来，给它取个名字。写代码时，你会反复做同一件事（比如把文本拼起来、计算价格），每次都复制粘贴很麻烦，函数就是解决这个的：定义一次，处处调用。可以把函数想象成一台『豆浆机』：你投入豆子（参数），它输出豆浆（返回值）。

Python 里用 def 定义函数：def 函数名(参数): 下面是函数体。函数体最后用 return 把结果交出来。调用时写 函数名(参数) 就能拿到返回值。AgentScope 教程里你写的 sys_prompt、name 等大多是传给 Agent 的字符串参数，理解函数的参数与返回值，就能看懂这些调用。

def greet(name):
    return "你好，" + name + "！"

msg = greet("小明")
print(msg)
预期输出
你好，小明！
操作步骤
  1. 用 def 定义函数 greet，接收一个参数 name
  2. 函数体里用 return 返回拼好的字符串
  3. 调用 greet("小明") 并把结果打印出来
要点
  • 函数 = 打包可复用代码，def 定义、return 返回
  • 调用时括号里传参数，得到返回值
  • AgentScope 里大量 API 都是『传参数、拿结果』的形式

类与对象

类（class）是把『数据 + 操作这些数据的方法』打包在一起的结构。可以把它想成一张设计图纸：图纸本身不是房子，但按图纸能造出很多房子（对象）。比如一个 Agent 有名字、有系统提示词（数据），有『回复消息』的能力（方法），在 AgentScope 里 Agent 就是一个类，你用类创建一个个具体的智能体实例。

定义类用 class 类名:，类里用 def __init__(self, ...) 定义初始化方法（self 指实例自己），普通方法也写在类里。创建实例用 类名(参数)。教程中 ReActAgent(...) 就是创建 Agent 实例的过程，理解类与实例的关系后，你就知道每个 Agent 各自拥有独立的状态。

class Robot:
    def __init__(self, name):
        self.name = name

    def say_hi(self):
        return "我是 " + self.name

r = Robot("小助手")
print(r.say_hi())
预期输出
我是 小助手
操作步骤
  1. 用 class 定义 Robot 类，__init__ 里保存 name
  2. 定义 say_hi 方法返回自我介绍
  3. 创建实例 r = Robot("小助手") 并调用方法
要点
  • 类 = 图纸，对象 = 按图纸造出的实例
  • self.name 是实例自己的数据，各实例互不干扰
  • AgentScope 中 ReActAgent 就是类，教程代码在创建实例

async/await 与 asyncio.run

异步（async）让程序在等待时（比如等模型返回）先去干别的，而不是傻等。可以把它想成点外卖：你下单后不会一直盯着手机发呆，而是边做别的事边等外卖。Python 用 async def 定义『协程』（可暂停的函数），用 await 暂停等待某个异步操作完成，最后用 asyncio.run() 启动整个异步程序。

AgentScope 的 Agent 调用是异步的：await agent(...) 这样的写法意味着『调用 Agent 并等它回复』。初学者最常犯的错是忘写 await（报错说 coroutine 未被等待），或忘了用 asyncio.run() 启动（直接调用协程不会执行）。记住一个模板：入口函数写成 async def main(): ...，最后 asyncio.run(main())。

import asyncio

async def say_hello():
    print("开始")
    await asyncio.sleep(1)   # 模拟等待
    print("结束")

asyncio.run(say_hello())
预期输出
开始
（停顿 1 秒）
结束
操作步骤
  1. 用 async def 定义协程函数
  2. 函数内用 await 等待异步操作（示例用 asyncio.sleep 模拟）
  3. 用 asyncio.run() 启动协程
常见坑
  • 调用 async 函数但不 await：报 TypeError 提示 coroutine 未等待
  • 忘了 asyncio.run()：协程只创建不执行，看不到任何输出
  • 在同步函数里直接 await：语法错误，async 只能在 async 函数内
要点
  • async def 定义可暂停函数，await 暂停等待
  • asyncio.run(入口()) 启动异步程序，是固定模板
  • AgentScope 的 Agent 调用要 await，教程代码以此为准

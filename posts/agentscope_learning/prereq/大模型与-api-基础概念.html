大语言模型（LLM）是什么

大语言模型（Large Language Model，LLM）是经过海量文本训练的程序，核心能力是『根据前文预测下一个词』，逐词生成连贯的回复。可以把它想成一个读过海量书籍的『接话大师』：你给它一句话，它能顺着接出非常自然的下一句，接得足够多就成了完整回答。

现代 LLM（如 GPT、Qwen）不仅能接话，还能理解指令、推理、写代码、总结文档。但它不是数据库也不是搜索引擎：它『记得』的是训练时见过的规律，可能编造细节（幻觉）。在 Agent 场景里，LLM 充当智能体的『大脑』——接收消息、决定下一步做什么。理解这一点就明白为什么 Agent 需要模型：没有模型，Agent 只是个空壳。

要点
  • LLM 是文本生成模型，根据前文预测下一个词
  • 能理解指令、推理、写代码，但可能产生幻觉
  • Agent 用 LLM 当大脑：决定想什么、说什么、做什么

API 与 API Key：一次调用的全过程

API（Application Programming Interface，应用程序接口）是程序之间通信的约定：你的代码向模型平台发一个 HTTP 请求，平台把模型生成的文本返回给你。整个流程是：你的程序带上『提示词（prompt）』和『身份凭证（API Key）』请求模型服务 → 平台把文本切成小块（token）让模型逐个生成 → 返回完整回复。token 是模型计费的最小单位，大致 1 个汉字约 1~2 个 token。

API Key 是你的身份凭证，就像门禁卡——只有带卡才能调用模型，调用按 token 计费。安全要点：Key 不要写进代码里提交到 GitHub，通常放到环境变量（教程中写作 os.environ["DASHSCOPE_API_KEY"]），程序运行时从环境变量读取。AgentScope 帮你封装了这套请求-响应过程：你只需配置模型与 Key，框架负责发请求、组装对话、拿回回复，这就是教程 L0 要做的『准备模型』。

操作步骤
  1. 去模型平台（如阿里云百炼 DashScope）注册并创建 API Key
  2. 把 Key 设为环境变量（Windows：setx DASHSCOPE_API_KEY 你的Key；macOS/Linux：export DASHSCOPE_API_KEY=你的Key）
  3. 在主教程 L0 用 os.environ 读取并创建模型对象
常见坑
  • 把 Key 写进代码或提交到公开仓库：会被盗用产生费用
  • 环境变量名拼写不一致：程序报 KeyError 或鉴权失败
  • 额度不足/欠费：请求返回 401 或余额错误，需到平台充值
要点
  • API = 程序调用模型服务的接口，发请求拿回复
  • token 是计费单位，1 个汉字约 1~2 token
  • API Key 是凭证，放环境变量、勿进代码库
  • AgentScope 封装调用细节，你只需配置模型与 Key
